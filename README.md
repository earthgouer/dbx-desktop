# DBX Desktop

[English](README.en.md) | **中文**

DBX Desktop 是 `dbx` 命令的轻量桌面启动器。应用启动时会检查 `http://127.0.0.1:4224`：如果 dbx 已经在运行，会直接在窗口中打开；否则会执行本机 PATH 中的 `dbx` 命令并等待服务就绪。

## 功能

- 自动查找系统 PATH 以及常用全局安装目录中的 `dbx` 命令。
- 直接执行 `dbx`（dbx 的默认端口为 **4224**）。
- 服务就绪后在应用窗口内打开 `http://127.0.0.1:4224`。
- 退出时只终止由本应用启动的 dbx 进程；用户自行启动的 dbx 不受影响。
- 移动端可连接局域网中的 dbx 服务，默认端口为 4224。

## 使用

确保在终端中可以直接运行 `dbx`，然后启动此应用即可。

```bash
npm install
npm run tauri dev
```

构建安装包：

```bash
npm run tauri build
```

## 工作方式

1. 启动时探测 `127.0.0.1:4224` 是否返回有效 HTTP 响应。
2. 若服务未运行，则执行 `dbx`。
3. 轮询端口 4224，服务就绪后跳转至本机 dbx 页面。

应用启动的 dbx 输出写入系统应用日志目录的 `dbx.log`。
