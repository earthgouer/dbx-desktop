## 追加：麒麟 V10 真机报错修复（dangerousRemoteDomainIpcAccess）

- 现象：AppImage 在麒麟上能启动、页面能打开/下载，但弹窗报
  `加载已保存连接失败: undefined is not an object (evaluating 'window.__TAURI_INTERNALS__.invoke')`。
- 根因：dbx-desktop 是 launcher，检测到 dbx 后 `window.location.replace(http://127.0.0.1:4224)`
  在 webview 里打开 dbx web UI；该页面调 `__TAURI_INTERNALS__.invoke` 读已保存连接，
  但 **Tauri v1 默认不向外部 http 域注入 IPC 桥** → undefined。
- 修复（commit bb6b247）：tauri.conf.json 的 `tauri.security` 加
  `dangerousRemoteDomainIpcAccess: [{ scheme: http, domain: 127.0.0.1, windows: [main] }]`
  （DBX_HOST=127.0.0.1，非 localhost——domain 必须精确匹配）。
- 修复版重建成功：run 33030791982，artifact dbx-desktop-appimage 70.5MB（id 9630241079，保留至 9/26）。
- 临时 push 触发器已再次移除（a2ea6e8）。
- 经验：launcher 型 Tauri 应用跳转外部 http 页面且需要 IPC 时，必须配
  `dangerousRemoteDomainIpcAccess`；domain 用实际 host（127.0.0.1 而非 localhost）。
